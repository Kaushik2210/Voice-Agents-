# Voice Agents

A collection of voice-AI projects, each in its own folder with its own README,
setup steps and tests.

| Project | What it is | Stack |
|---|---|---|
| [ClinicScribe](ClinicScribe/) | Private consultation notes for clinics. Local speech-to-text and a local LLM draft a SOAP note with every line linked back to the transcript. | FastAPI, React, VoiceStudio, Ollama |

More projects will be added here as they are built.
